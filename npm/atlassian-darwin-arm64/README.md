# `@bitefoundry/atlassian-darwin-arm64`

Platform-specific prebuilt `jira` binary (`aarch64-apple-darwin`) for [`@bitefoundry/atlassian`](https://www.npmjs.com/package/@bitefoundry/atlassian).

Install the main package instead of installing this package directly:

```sh
npm install -g @bitefoundry/atlassian
```
