# `@shinick/atlassian-win32-arm64`

Platform-specific prebuilt `jira.exe` binary (`aarch64-pc-windows-msvc`) for [`@shinick/atlassian`](https://www.npmjs.com/package/@shinick/atlassian).

Install the main package instead of installing this package directly:

```sh
npm install -g @shinick/atlassian
```
