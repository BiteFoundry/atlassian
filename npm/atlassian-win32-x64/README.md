# `@bitefoundry/atlassian-win32-x64`

Platform-specific prebuilt `atlassian.exe` binary (`x86_64-pc-windows-msvc`) for [`@bitefoundry/atlassian`](https://www.npmjs.com/package/@bitefoundry/atlassian).

Install the main package instead of installing this package directly:

```sh
npm install -g @bitefoundry/atlassian
```
