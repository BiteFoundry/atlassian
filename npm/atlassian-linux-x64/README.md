# `@bitefoundry/atlassian-linux-x64`

Platform-specific prebuilt `atlassian` binary (`x86_64-unknown-linux-gnu`) for [`@bitefoundry/atlassian`](https://www.npmjs.com/package/@bitefoundry/atlassian).

Install the main package instead of installing this package directly:

```sh
npm install -g @bitefoundry/atlassian
```
