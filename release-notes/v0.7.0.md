## Jira and Confluence writes

- Jira transitions report candidate IDs when a name matches multiple transitions. Select an ID to apply the intended transition. Assignee fields accept `me` and can resolve a rejected name or email address to a unique assignable user.
- Confluence space-key lookups follow pagination, including spaces beyond the first page.

## Compatibility

- Jira issue and Confluence page create/edit commands return compact JSON by default. Add `--full` to the CLI command or pass `"compact": false` to the matching MCP write tool for the full representation.
- Runtime failures with `--json` write an error object to stdout. Scripts can inspect `error.code` and `error.message` alongside the exit status.
- Scripts reading `account_id` at the top level of `login`, `whoami`, or `doctor` should read `credential_account` for the local credential identity.
