## What's Changed

### Confluence Page Tree & Auto-Expand Fixes
- Added `children.page` to Confluence Data Center `expand` parameters (`list_space_root_pages_page` & `list_child_pages_page`) so `has_children` reflects real child presence (`Some(true)` / `Some(false)` / `None`) instead of always falling back to unknown.
- Introduced `TreeRow.expandable` so pages with unknown child status (`None`) remain expandable (`▸` chevron, clickable hit target, `Enter` & double-click expand) instead of appearing as dead `·` leaves, and settle permanently to leaf once an empty child list is loaded and persisted.
- Auto-expanded the active space's Homepage (or sole root page) when root pages load, while respecting manual user collapses during the session (`user_collapsed_pages`).
