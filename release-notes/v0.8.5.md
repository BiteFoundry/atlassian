## What's Changed

### Sync & Multi-Product API Parallelization
- Parallelized all 4 independent domains in `run_full_sync_for_site` (Jira projects, Agile boards, my open issues, Confluence spaces) via `tokio::join!` while preserving per-domain circuit breakers and deterministic error reporting.
- Overlapped board columns, sprints, and issues across `sync_board`, `cmd_board`, and `request_board_load`; overlapped Jira+Confluence identity probes (`probe_identity`), issue+remotelink fetches, Confluence Cloud 4 subresources + ancestor title lookups (`buffer_unordered(4)`), Confluence DC page+comments, and sprint-move membership verification (`buffered(6)`).
- Memoized Cloud `/rest/api/3/project/search` fallback per `AtlassianClient` and added `get_myself_cached()` for repeated `assignee = "me"` lookups.

### Write Path & TUI Responsiveness
- Overlapped TUI `spawn_bootstrap` identity, workspace sync, and favourite-filter fetches, plus multi-site `My Work` and unified Jira+Confluence remote searches (`serve`, `mcp`, TUI).
- Updated cached comment and attachment mutations to append directly to SQLite without redundant full issue/page refetches, and switched attachment download lookups to lightweight attachment-only endpoints.
- Added bounded interactive sibling prefetching (budget 3, concurrency 2) for uncached Jira issues and Confluence pages in TUI, and fixed cross-site immediate display for newly created pages.

### Test Hardening
- Guarded unit-test config and draft persistence from mutating the host user config directory and aligned the compact CLI `view` hint e2e assertion.
