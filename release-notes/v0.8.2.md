## Jira Compact Reads & Selective Field Projection

- **Populated Jira custom fields now appear in compact `omitted.custom_fields`.** `get_issue_with_meta` passes `expand=names` on the same Jira API request (zero extra HTTP calls), stores non-empty `customfield_*` entries (with display names and Markdown rendering for ADF custom fields) in `IssueDetail.custom_fields`, and lists `{ id, name }` entries in `omitted.custom_fields` so AI agents can distinguish "not shown" from "not present" (for example, Acceptance Criteria stored in a custom field).
- **Fetch only specific omitted or custom fields by issue key without pulling the full ticket:**
  - **MCP (`get_jira_issue`)**: pass `fields: ["Acceptance Criteria", "comments"]` (accepts standard omitted field names, `customfield_<id>` keys, or case-insensitive custom field display names; works online and with `offline: true` against local SQLite).
  - **CLI**: `atlassian view KEY --json --fields "Acceptance Criteria,comments"` (and `atlassian jira view`).
  - **HTTP API**: `GET /issues/{key}?fields=Acceptance%20Criteria,comments`.
  - Truly absent fields are returned explicitly in `missing_fields`, and incomplete collections remain flagged in `incomplete`.
