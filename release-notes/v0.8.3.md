## What's Changed

### Shell Alias Support (`tcsh`, `csh`, POSIX `sh`) & Safe Shell Detection
- Added `tcsh`, `csh`, and `sh` (`dash`/`ash`/`ksh`) to `ShellKind` for `atlassian init` and `atlassian alias install|uninstall|status`.
- Replaced loose substring `$SHELL` matching with exact basename detection (stripping login `-` prefixes and `.exe`) and an explicit error on unsupported `$SHELL` values instead of silently editing `~/.bashrc`.
- Protected existing `~/.cshrc` setups for `tcsh` users (uses `~/.cshrc` when `~/.tcshrc` is absent so existing `.cshrc` configs are never shadowed) and preserved symlinked/dangling RC files.

### Symlinked `$HOME` & Path Hardening
- Added `canonicalize_existing_ancestor` so daemon Unix socket hashes stay consistent across symlinked and canonical `$HOME` paths, and isolated `XDG_RUNTIME_DIR` fallback sockets per profile.
- Preserved dotfile symlinks in `write_atomic` for user config files while refusing symlink writes on `0600` credential/secret files.
- Expanded leading `~/` on `ATLASSIAN_CONFIG_DIR`, `ATLASSIAN_DATA_DIR`, and external `$EDITOR`/`$VISUAL` program paths.
- Resolved symlinked executable paths before self-updating in `updater.rs` so symlink installs update the target binary cleanly.
