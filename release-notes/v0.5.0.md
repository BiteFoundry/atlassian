Run `atlassian mcp --read-only` or `confluence mcp --read-only` to expose 15 lookup and search tools. Direct calls to unavailable tools are rejected. The default mode continues to provide all 37 tools.

Confluence Cloud section editing finds headings at the page root and inside layout columns. A unique match updates its own section. Duplicate headings produce an error before saving.

Jira and Confluence editing, comments, searches and worklogs accept hyphen-prefixed Markdown and other text as separate CLI arguments.
