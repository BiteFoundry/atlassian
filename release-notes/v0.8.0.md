## Shell Aliases & Short CLI Ergonomics

- Added opt-in shell alias management (`atlassian alias install|uninstall|status` and `atlassian init <powershell|zsh|bash|fish>`) registering guarded `j` (Jira) and `cf` (Confluence) functions without global PATH collisions. On Windows, installation targets both PowerShell 7 and Windows PowerShell 5.1 profiles automatically.
- Added smart view shorthand (`atlassian ENG-42 -j`, `conf 40211 -j`, `atlassian wiki 40211`, `conf jira ENG-42`), positional `create`/`assign`, short command aliases (`mv`, `q`, `e`, `c`, `as`), and single-letter short flags (`-j`, `-f`, `-o`, `-r`, `-n`, `-p`, `-P`, `-t`, `-s`, `-b`, `-a`, `-l`, `-m`, `-c`, `-u`, `-y`) including combined short flags like `-mj` and `-rj`.

## Documentation & Polish

- Standardized all user-facing CLI messages, error hints, updater notices, and API documentation to English.
- Added an AI-agent workflow showcase to `README.md` covering `24×` smaller compact reads (`1,076 B` vs `25,834 B`), `replace_section` + `dry_run` previews, `prev_version` concurrency guards, and `atlassian mcp --read-only`.
