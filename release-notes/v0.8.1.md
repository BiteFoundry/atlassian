## Behaviour Changes

- **`serve` is closed to cross-origin browsers by default.** No CORS headers are sent unless `serve` is started with `--cors-origin <ORIGIN>` (repeatable, exact origins; `*` is rejected), requests whose `Origin` is not allowlisted get `403`, and a loopback bind refuses non-loopback `Host` names. Binding a non-loopback address now requires `--token`. Clients that send no `Origin` header (curl, scripts, agents) are unaffected.
- **MCP `assign_jira_issue` requires `assignee_id`.** `null` unassigns; omitting the argument is an error instead of an unassign. Every MCP tool now rejects arguments its input schema does not declare.
- **An unknown `site` is an error.** MCP tools and the HTTP `/search` and `/sync` endpoints reject a mistyped per-call `site` with an error naming the configured sites (HTTP `400`) instead of returning an empty result; other HTTP endpoints answer `404 site not found` as before. `all` stays federated for reads and is refused for writes.
- **Offline issue listing filters before the limit.** `issues --offline` honours `--status` and `--mine` (from the identity `whoami` caches per site) and refuses `--jql`; `GET /issues?offline=true&jql=…` is a `400`.
- **Board refresh detaches instead of deleting cached issues.** A board or sprint prune clears the issue's board or sprint link; the issue, its cached detail and its search entry stay.
- **Environment PATs in multi-site configs** are primary only for the site whose URL they name and a fallback for the others. Single-site setups are unchanged.
- **`sites default`** clears a persisted TUI site selection that would otherwise shadow the new default (JSON output adds `cleared_active_site`).
- **`SprintSummary.board_id`** is now the board the sprint was listed under; the sprint's own board is the new `origin_board_id`.

## Enterprise & Data Center

- Trust the OS certificate store next to the bundled roots, and load extra root CAs from `ATLASSIAN_EXTRA_CA_PEM` (path or inline PEM), `SSL_CERT_FILE` and `NODE_EXTRA_CA_CERTS` on every HTTP client. An untrusted-issuer failure names these variables and `atlassian doctor --probe`; unusable bundles are reported on stderr only, so MCP stdio stays clean.
- Data Center sites can use a separate Confluence PAT (`login --confluence-pat`, `--confluence-account`, `confluence_account_id` or `ATLASSIAN_CONFLUENCE_PAT`). It is only sent to URLs under the Confluence root.
- Jira and Confluence identities are probed separately, so `login`, `whoami` and `doctor --probe` work on Confluence-only hosts. A `2xx` answered to an anonymous session (login page, `X-AUSERNAME: anonymous`, failed `X-Seraph-LoginReason`) is reported as `401` with a product hint instead of as an empty result.
- `doctor` reports `tls`, `env_credentials`, `confluence_credential_account`, `config_dir`, `config_dir_source` and `data_dir`; login failures explain how to pass the credential directly when the hidden prompt fails.

## Sync & Cache Correctness

- Caches are pruned only after every page of a listing was walked and the server reported the end, so servers that cap their page size no longer make the cache drop the rest. Spaces, my issues, board and project issues, root pages, sprints, comments and attachments follow every page.
- HTTP list endpoints (`/boards/{id}/issues`, `/spaces`, `/spaces/{space}/pages`, `/pages/{id}/children`) take an optional `cursor` and return `has_more` / `next_cursor`.
- Removing a Confluence page from the cache also removes the pages cached below it; a sprint shared by several boards is linked to each; an empty `updated_at` no longer overwrites a cached timestamp; issue comment totals keep the server's count.
- `--replace-section` no longer deletes a following layout whose columns start sibling sections.

## Multi-Site

- `daemon run`, `serve` sync, MCP `sync_workspace` and the board / project / space refresh commands follow the configured `[[sites]]`; pool-built clients keep each site's default project, board and space.
- `sites remove` deletes the cache by canonical site id, and removing the last site clears the legacy URL fields; OAuth, cloud-account login and discovery keep an existing single-site configuration.
- TUI: writes (transition, assign, assign-to-me, comment, edit/create, upload, pin) go to the site of the selected row; Confluence tree caches, attachment previews and drafts are kept per site; Back history and cross-links reopen items on the site they came from; "me" is resolved per site.

## Confluence SPACES Pane

- The Wiki tab opens on the configured `default_space_key` (and the Board tab on `default_board_id` / `default_project`), also after a site switch; a background sync no longer moves a selection you made.
- The SPACES pane scrolls to keep the selected space in view, also in All Sites mode; its title shows ▲/▼ and your position when the list is cut off, and the mouse wheel moves the selection.
- Press `/` in the SPACES pane to filter spaces as you type. Matches rank by key, then name; a leading `~` shows only personal spaces. `Enter` opens the selected space and `Esc` clears the filter, then closes it. While the filter is open, letter keys type into it instead of running shortcuts.
- Creating a page in a personal space shows a banner; in someone else's personal space you submit twice to confirm.
## Windows

- The startup lock no longer spins when a stale lock file cannot be removed.
- `$EDITOR` values with quotes, spaces in paths, or `.cmd` shims such as `code --wait` launch correctly.
- The updater unpacks `.zip` assets with `System32\tar.exe` (falling back to `Expand-Archive`) instead of the first `tar` on `PATH`.
- Attachment names like `CON .txt` are made safe, and names are capped at 255 bytes with the extension kept; `alias install --force` replaces an existing PowerShell alias.

## TUI

- Task spinners finish on every success and failure path, and a leaked spinner expires after 120 s.
