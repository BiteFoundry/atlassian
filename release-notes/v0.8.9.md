## What's Changed

### Modular Architecture, Cycle Cuts & Terminal Safety
- **Terminal & Agent Safe-Output (`src/safe_text.rs`)**: Sanitized untrusted Jira/Confluence text rendered to CLI output (issues, pages, Kanban boards, lists, search) against ANSI/VT100 escape sequences (CSI/OSC/DCS/C1), C0/C1 control characters, Unicode Bidi overrides (Trojan Source), and invisible Unicode Tag prompt-injection characters (`U+E0000..=U+E007F`), while preserving raw `--json` output.
- **Supply Chain & Packaging**: Added `[package.metadata.binstall]` for `cargo-binstall`, `deny.toml` + `.github/workflows/audit.yml` (`cargo-deny` CI), and `refs/tags/v` tag guards on release jobs.
- **Codebase Modularization & Dead-Code Cleanup**: Pruned unused resolver/wrapper code, unified env-var test locking, decomposed `src/mcp.rs`, `src/cli.rs` (with `#[command(flatten)]` persona deduplication), `src/ui/app.rs` (`handle_ui_msg` 1,137L → 35L router), and E2E suites into cohesive domain modules, and cut all 4 targeted module cycle edges (`atlassian/client ↔ confluence` and `ui/overlays → ui/app`).
